欢迎来到 KiraAI 手机版

KiraAI 是一个以数字生命为中心的 AI 项目，可以连接多种模型和聊天平台。这个应用让它直接运行在你的手机上。

四步开始

  1. 01

    准备运行环境

    首次打开会自动下载并安装运行环境，需要联网，耗时取决于网速。进度显示在首页“运行组件”。

  2. 02

    进入 KiraAI 面板

    准备好后点底栏的 KiraAI。登录令牌在“菜单 → KiraAI 首次默认令牌”。

  3. 03

    添加模型

    在官方面板里填写模型服务商和 API 密钥，KiraAI 就能开始对话。

  4. 04

    连接聊天平台（可选）

    要接入 QQ，可在首页安装本机 NapCat（xxynet 维护的 fork 版本），或在面板里连接远程 NapCat。

系统可能在后台中断 KiraAI。建议允许后台运行，并关闭本应用的电池优化。

之后可以在“菜单 → 新手引导”重新打开这一页。
